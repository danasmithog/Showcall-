# Showcall

Every cue, every crew member, on time. Showcall turns a BEO into a live run of show that calls each cue to the crew's phones and watches.

- **Install on a phone:** open https://danasmithog.github.io/Showcall-/app.html in Chrome (Android) and tap ⋮ › Install app, or in Safari (iPhone) tap Share › Add to Home Screen.
- **Website:** https://danasmithog.github.io/Showcall-/
- **Owner portal:** https://danasmithog.github.io/Showcall-/owner.html

The demo runs on a sample gala with generic names. Demo data stays on each device; it works offline after the first open.
